Frequently Asked Questions

Everything You Need to Know

Have a question? We have answers.

Can I use this business plan to apply for an SBA or bank loan?

Yes. The generated plans follow standard SBA loan guidelines and commercial bank requirements, including executive summary, management breakdown, market viability, break-even analysis, and 5-year financial schedules.

How accurate are the financial calculations?

Our financial calculations are not estimated text generated by an LLM. They are computed on the backend using Java 21's BigDecimal class, ensuring zero floating-point errors across startup cost allocations, break-even unit volumes, and multi-year CAGR models.

Can I edit and customize the plan after it is generated?

Absolutely. The built-in 3-column Document Studio allows you to click into any of the 30 sections, edit markdown in real time, ask the AI Copilot to refine specific paragraphs, and download the finished result as an editable Microsoft Word (.docx) or PDF document.

Do I need an OpenAI or Google Gemini API key to use this?

No API key is required. The platform operates seamlessly in autonomous demo mode with comprehensive pre-trained generation templates, or with a cloud Gemini API key configured securely in the backend environment.
